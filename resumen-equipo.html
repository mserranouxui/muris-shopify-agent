📈 Muris Growth & Marketing Specialist

SEO, paid, social/influencers y growth

Estrategia de adquisición para las mismas cuatro disciplinas que ya conocemos por separado — ahora en un solo agente, pensado para mujeres 25-45 y con el enfoque UGC/influencers como palanca principal. Coordina con el agente de Shopify para cualquier cambio técnico on-site.

Los dos comparten una regla fija: antes de cualquier cambio real — gastar en ads, publicar, tocar precios, editar el tema en vivo — explican qué van a hacer, piden confirmación, y la vuelven a pedir justo antes de ejecutar. Nunca actúan con una sola aprobación.

Cómo lo pone en marcha cada persona

Cinco minutos, una vez por persona y por Mac.

  1. Pedir acceso al repo

    Confirmar con Manuel que tu usuario de GitHub está invitado como colaborador de muris-shopify-agent.

  2. Clonar el repo y abrirlo con Claude Code

    Los dos agentes aparecen solos al abrir la carpeta — no hace falta instalar nada para eso.

  3. Instalar las skills oficiales de Shopify

    Dentro de una sesión de claude en terminal:

    /plugin marketplace add Shopify/liquid-skills /plugin install liquid-skills@liquid-skills
  4. Instalar las skills de marketing

    50 skills de SEO, paid, social, growth y más — misma sesión de claude:

    /plugin marketplace add coreyhaines31/marketingskills /plugin install marketing-skills@marketingskills
  5. Conectar tu propia app de Shopify (si vas a tocar la tienda)

    Sigue ONBOARDING-shopify.md dentro del repo — cada persona crea su propia app en el Dev Dashboard, con sus propias credenciales. Nunca se comparte una misma app entre varias personas.

Cualquier duda sobre esto, hablar con Manuel (Eunoia). Última actualización de este resumen: 11 de septiembre de 2026.
